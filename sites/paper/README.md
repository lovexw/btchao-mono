# 比特币白皮书（中文版）· 小吴乐意翻译版

> Bitcoin: A Peer-to-Peer Electronic Cash System — 中本聪 著，2008
> 小吴乐意 译，2026 · 线上阅读：<https://paper.btchao.com>

中本聪《比特币：一种点对点的电子现金系统》的全新中文译文站点。翻译原则是**先说人话，再读原文**：每一节先用大白话讲清楚「这节在干嘛」，再给出逐句忠实、一个段落不删的译文，并可展开英文原文逐段对照。

## 内容

- **导读**：三分钟读懂比特币——它是什么、难在哪、怎么解、凭什么可信，以及不同读者的阅读路线
- **全文重译**：摘要 + 12 节 + 参考文献，段落与原文一一对应
- **先说人话**：每节的大白话导读，与译文严格区隔
- **英文原文**：每节可展开折叠，方便对照核对
- **图解**：交易签名链、时间戳链、区块链结构、默克尔树，共 4 幅
- **互动演示**（浏览器本地运行，无任何数据上传）：
  1. 哈希指纹机 —— 雪崩效应
  2. 挖矿模拟器 —— 亲手找一次 nonce，体会指数难度
  3. 篡改实验室 —— 改动一个区块，看链条如何报警、为何要重挖后面所有区块
  4. 确认数计算器 —— 按第 11 节公式实时计算「等几个确认才安心」
- **常见答疑**：读论文时最常问的 10 个问题
- **术语表**：20 个核心术语
- **译后记**：翻译约定、术语对照、版权说明

## 技术实现

- 纯静态：`index.html` + `styles.css` + `script.js`，零依赖、零构建、无外部字体与 CDN，国内访问友好
- 深浅色双主题（跟随系统 + 手动切换，本地记忆）
- 桌面端侧边目录 + 阅读进度 + 滚动高亮；移动端自适应
- SHA-256 为页面内置实现，演示完全离线可用；打印样式友好
