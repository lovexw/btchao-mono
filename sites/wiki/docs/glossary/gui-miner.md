# GUI 挖矿软件

> **一句话定义：** 早期比特币 CPU/GPU 挖矿时代的图形界面前端应用，ASIC 统治后已淘汰。

GUI 挖矿软件是一个历史品类：带图形界面的消费级比特币挖矿软件，流行于 2011–2013 年的 GPU 挖矿时代。具体程序「GUIMiner」（puddinpop / Chris Moore，2010–2012）把 cgminer、bfgminer、Phoenix 这类命令行挖矿工具包上可点击的界面，让用户连上矿池、指向自己的显卡、开始哈希。

这个品类为什么消亡：

- **2013 年起 ASIC 统治。** 随着 Avalon 和蝴蝶实验室（Butterfly Labs）发出第一批 ASIC，比特币算力从 GH/s 跳到 TH/s。GPU 在数月内丧失竞争力。到 2014 年，GPU 挖比特币永久性不盈利。
- **ASIC 的管理方式不同。** ASIC 自带嵌入式固件（蚂蚁矿机的 Linux、原厂或第三方固件），通过 Stratum 协议连矿池，用设备自带的 Web 界面或机群管理软件管理。不需要另一台电脑上的桌面 GUI。
- **市场变味了。** 爱好者活动变成了工业活动。软件生态随之转移：Awesome Miner、Braiins Farm Proxy、Hive OS 之类的工具取代了 GUI Miner 式的消费级软件。

这个品类如今仍然存在的形态：

- **矿池仪表盘。** 矿池网站（Foundry、AntPool、F2Pool、ViaBTC）上的 Web 界面，矿工查看自己的算力贡献与收益。
- **ASIC 的 Web UI。** 每台 ASIC 自带配置用的 Web 界面，局域网内可访问。
- **机群管理软件**，如 Awesome Miner、Braiins Farm Manager、Foreman，服务管理几十到几千台 ASIC 的运营者。

GUI Miner 本身已是博物馆藏品。如果你看到一份推荐用它挖矿的老教程，那份教程至少过时十年了。
