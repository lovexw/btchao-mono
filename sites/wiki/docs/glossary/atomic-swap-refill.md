# 原子交换充值（Atomic Swap Refill）

> **一句话定义：** 用原子交换在链下或侧链间再平衡流动性或重挂资产，无需依赖中心化服务。

原子交换充值，指用[原子交换](/glossary/atomic-swap)（基于 HTLC 的无信任交换）来再平衡流动性的技术，最常见于闪电[通道](/glossary/payment-channel)。不必关通道再上链开新通道（贵、慢、公开），你可以把通道外的余额换成通道内的余额，或者在自己参与的两条通道之间腾挪。

闪电网络上的经典场景：一个路由节点发现某条通道「干涸」（没有出站容量），另一条却「满仓」（资金全在自己一侧）。上链再平衡意味着烧手续费、等确认。原子交换充值让节点通过与另一个节点做交换，把余额在两条通道间调配，不动链上交易就恢复路由容量。

实际实现：

- **潜艇交换（submarine swap）**：闪电余额与链上 BTC 互换。既用于再平衡，也用于「不开新通道、直接从链上给闪电钱包充值」。
- **Loop 与 Loop Out（Lightning Labs 的服务）**：商业化的潜艇交换服务，做出站/入站流动性。
- **PeerSwap**：两个有共同通道的闪电节点之间点对点的再平衡协议。

共同的诀窍是原子性。交换的两条腿要么都发生要么都不发生，全程没有任何受信任的中间人持有资金。密码学与闪电路由本身用的是同一套哈希锁合约模式。

小众，但随着闪电路由的成熟越来越重要。通道容量管理是运营路由节点的日常现实，而基于原子交换的再平衡是其中便宜的那条路。
