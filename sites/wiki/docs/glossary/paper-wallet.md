# 纸钱包（Paper Wallet）

> **一句话定义：** 打印出来的私钥（和地址），用于离线保存 BTC。生成得当则安全，但物理上脆弱。

纸钱包，是把[私钥](/glossary/private-key)（和对应[地址](/glossary/address)）打印到纸上——通常附二维码——以物理而非数字方式保存。2012–2014 年间最常见的冷存储形态；如今大多已被淘汰。

当年的吸引力：零数字攻击面。一张纸没法被从互联网黑进来、跑不了恶意软件、也没法被远程窃取。离线生成，找个安全的地方一放，完事。

纸钱包为什么失宠：

- **单钥匙的脆弱性。** 纸钱包通常只备份*一把*私钥。只要花掉其中任何一部分，就必须把整个余额扫到新地址（因为 Bitcoin Script 不允许部分花费一个 [UTXO](/glossary/utxo-unspent-transaction-output)）。大多数「我因为纸钱包错误丢了 BTC」的故事，根源都是不理解这一点、把找零发去了虚无。
- **生成环节的风险。** 纸钱包的安全性取决于生成时用的熵。在线「纸钱包生成器」屡次被发现留后门；离线工具则需要严格的气隔操作。
- **物理脆弱性。** 纸会烧、会潮、会褪色、会被当废纸扔掉。这种介质谈不上档案级保存。
- **生态不成熟。** 现代钱包没法干净地导入单钥匙纸钱包；你得跟扫币、手续费管理、兼容性搏斗。

现代替代方案是[助记词](/glossary/seed-phrase)备份（钢板、钢垫圈、蚀刻钛板），配合日常使用的[硬件钱包](/glossary/hardware-wallet)。气隔属性与纸钱包相当，其他一切实用维度全面碾压。

如果翻出一张老纸钱包：小心地整笔扫出（整个 UTXO，不要部分花），让这个地址退役，迁移到现代 HD 配置。别再生成新的了。
