# 定投（DCA）

> **一句话定义：** 固定时间间隔投入固定金额买入比特币，降低短期波动带来的择时压力。

定投（dollar-cost averaging）是按固定日程买入固定金额比特币的策略，不管价格几何。每周五 100 美元，每个发薪日 50 美元。节奏随你定，但规则不变：金额固定、间隔固定、没有例外。

它的优势更多是心理上的而非数学上的。你不必再判断今天的价格是不是好的入场点——这个问题你在设定计划的那一刻就已经一次性回答了。你永远不是「买在山顶」，因为下周你会按当时的价格再买一次。足够多个周期之后，你的平均成本会落在一个合理的区间。

若干比特币专精服务（Strike、Swan、River 等）以及多数主流交易所都能把这件事自动化。设置一次，然后忘掉它。「设完就忘」占了这项策略价值的大部分——定投首先是对抗你自己那套不可靠的择时直觉的防御工事。

如果你碰巧精准抄到了底，定投不是收益最高的策略。但对于没法稳定抄底的普通人，它是现实中的最优策略。

另见 [HODL](/glossary/hodl)——定投就是 HODL，只是不断叠加新买入。
