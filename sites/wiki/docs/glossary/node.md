# 节点（Node）

> **一句话定义：** 运行比特币软件、验证并转发区块与交易的计算机，执行网络共识规则。

比特币节点是运行比特币软件、参与点对点网络的计算机。它接收[交易](/glossary/transaction)和[区块](/glossary/block)，对照共识规则逐一验证，再把有效的转发给对等节点。

实践中节点分两种：

- **[全节点](/glossary/full-node)** 从[创世区块](/glossary/genesis-block)开始下载并验证每一个区块，维护完整的 UTXO 集、独立执行每一条共识规则。这是「无需信任」的黄金标准。
- **SPV（简化支付验证）节点** 只下载区块头，靠全节点用默克尔证明确认交易已入块。轻得多（几 MB 对几百 GB），代价是放弃部分验证保证。

节点是比特币执行规则的方式：矿工*提议*区块，节点*接受或拒绝*。矿工产出无效区块——补贴超发、签名无效、交易畸形——全网每个诚实节点都会无视它。这就是那句名言「比特币由节点治理，而不是矿工」成立的原因：算力决定哪条*有效*历史获胜，节点决定*有效*是什么意思。

当前网络约有 15,000–20,000 个公开可达的全节点，外加数量更大、无法精确统计的隐蔽节点（躲在 NAT 后、跑在 Tor 上）。这种分布式的执行，才是比特币安全模型真正的脊梁。

跑一个节点实际是什么样，见[全节点](/glossary/full-node)；为什么你应该跑一个，见[第 6 章 · 主权](/journey/sovereignty)和[运行自己的节点](/node)。
