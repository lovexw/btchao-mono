# 第三方矿机固件（Proprietary Mining Firmware）

> **一句话定义：** 替换 ASIC 厂商默认固件的自制固件，以优化性能或能效。

第三方矿机固件是替换 ASIC 厂商原厂固件的第三方固件，提供更好的性能、更细粒度的控制，或厂商没出厂的功能。在工业级比特币挖矿中，这是一个有分量的细分市场。

运营者安装它的理由：

- **更好的每瓦算力。** 定制固件可以在原厂固件未暴露的非默认电压/频率组合下运行芯片。比原厂提升 10–20% 能效很常见。
- **细粒度调优。** 按板、按芯片调频率和电压，而不是全机一个设置。这对补偿同一机群里芯片的天然硅片差异很有用。
- **更好的遥测。** 芯片级温度、功耗、错误率的详细监控——原厂固件经常藏起这些。
- **自动调频。** 自动为每颗芯片、每种散热条件寻找最优频压组合。
- **矿池故障切换与 Stratum V2 支持。** 更好的连接管理，有时领先于原厂固件。
- **需求响应。** 一些固件接入 ERCOT 式电网信号，在电价飙升时动态削减挖矿负荷。

主要供应商（截至 2026）：

- **BraiinsOS / BraiinsOS+**（Braiins / Slush Pool）。开源内核 + 商业高级版。业内口碑好。
- **VNish**（Vnish.online）。俄罗斯团队开发，在老代际蚂蚁矿机上流行。闭源。
- **LuxOS**（Luxor Technology）。面向运营工具链的商业固件。
- **Hiveon ASIC**（Hive OS）。云端管理的替代方案。

代价：

- **失保。** 厂商对刷了非原厂固件的设备不保修。
- **变砖风险。** 配置错误的固件可能损坏芯片（过压、热失控）。运营者会先小批量试刷，再推全机群。
- **授权费。** 高级固件按设备或按收入比例收费。在工业规模下，能效收益通常足以覆盖成本。

对只有一台 ASIC 的爱好者，原厂固件够用。对运营几百台以上的运营者，第三方固件基本上是必需品——长期算下来，能效差价翻倍地回本。在规模上，固件部署、监控、矿池路由都由位于单机固件层之上的[挖矿前端](/glossary/mining-front-end)统一编排。
