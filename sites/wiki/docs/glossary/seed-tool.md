# 种子工具（Seed Tool）

> **一句话定义：** 在安全环境中离线生成、校验或转换 BIP 39 助记词种子的脚本或应用。

种子工具是离线软件，用来生成、校验或转换 BIP 39 助记词，而不必把随机性托付给硬件钱包或在线生成器。常见操作：

- **从物理熵生成种子。** 掷 99 次骰子（可提供 128+ 位真随机），把结果输入工具，得到对应的 12 或 24 词短语。全程不涉及任何软件 RNG。
- **格式互转。** BIP 39 词与原始熵之间来回转换。用于核验两份备份（打印的词 + 钢板錾刻）编码的是同一颗种子。
- **校验检查和。** 依赖一份手抄 24 词之前，先确认它内部自洽。
- **测试可选口令。** 对给定（助记词 + 口令）组合计算派生种子，验证它产出预期的地址。

实际存在的实现：

- **SeedSigner。** 无状态气隔设备：接收骰子投掷、产出种子、签署 PSBT，全程不持久化种子。
- **Ian Coleman 的开源 BIP 39 工具。** 在浏览器里运行，但设计上可下载后离线使用。常用来校验种子、派生地址、给钱包行为做交叉验证。
- **各种 Python / Rust CLI 工具。** 面向想核验自家钱包行为或搭建自定义备份工作流的开发者。

让种子工具真正有用的纪律：跑在气隔机器（或专用可信设备）上、使用经核实的开源版本、并在把有分量的金额托付给产出的种子之前，确认输出与你的钱包所见的完全一致。
