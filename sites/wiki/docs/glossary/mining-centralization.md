# 挖矿中心化（Mining Centralization）

> **一句话定义：** 比特币算力集中于少数大矿池带来的 51% 威胁担忧。

挖矿中心化是这样的担忧：比特币的[算力](/glossary/hash-rate)集中在太少的人手里，侵蚀比特币赖以生存的[去中心化](/glossary/decentralization)属性。

2026 年的结构性现实：

- **少数几个[矿池](/glossary/mining-pool)协调了大部分算力。** Foundry USA、AntPool、ViaBTC、F2Pool 等合计掌握超过全球一半的算力。
- **少数几家 [ASIC](/glossary/asic-application-specific-integrated-circuit) 厂商供应大部分硬件。** Bitmain、MicroBT、Canaan 等。
- **少数几个辖区托管大部分挖矿。** 美国最大，其后随年份不同各有先后。2021 年中国禁矿大幅改写了地理版图。

实践含义：

- **协同攻击理论上可行。** 合计控制 >50% 算力的矿池可以尝试重组近期区块、审查特定交易、双花自己的输出。这些在比特币上从未大规模发生，但能力是存在的。
- **存在单一施压点。** 想审查比特币交易的政府原则上可以对其辖区内的矿池运营者施压。较温和的版本已被观察到（部分矿池自愿过滤 OFAC 制裁地址）。

制衡是什么：

- **矿池不是矿工。** 矿池内的算力来自几小时内就能换池的个体矿工。作恶的矿池会迅速失血。
- **Stratum V2 的进展。** 新的矿池-矿工协议把交易选择权从矿池运营者转到个体矿工。采用是渐进的，但方向正确。
- **地理分散已改善。** 对比 2018–2020 年约 65% 算力在中国的时代，网络现在分布在多得多的国家。
- **矿机硬件是可搬移的。** 矿工随时可以、也确实会把算力接到不同辖区、不同矿池。

诚实的评估：挖矿中心化是一个有真实失败模式的真实担忧，但结构性制衡同样真实。它值得盯着、值得用 Stratum V2 采用和矿池监督去推回，但不值得恐慌。更长的分析见[挖矿：算力、难度与激励](/rabbit-holes/mining)。
