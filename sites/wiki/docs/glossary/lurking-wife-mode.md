# 「老婆围观模式」

> **一句话定义：** Bitcoin Core GUI 中隐藏钱包余额的非官方设置，开发者圈内的玩笑式提交。

「老婆围观模式」（Lurking Wife Mode）是一个真实存在（而且已发布）的 Bitcoin Core 功能：Qt 图形界面里的一个开关，把钱包余额和交易金额从界面上藏起来。目的是防背后偷看的人——名字里的「老婆」只是个梗，实际上防的是任何不该看到你账户的人。

这个功能由 Sjors Provoost 于 2015 年加入（PR #6489）。原始 commit 信息和 GitHub 讨论都顺着这个幽默走：名字是一个自觉的玩笑，说的是那个非常具体的现实场景——「你正在看比特币行情，配偶走进房间」。Bitcoin Core 的开发文化在代码上素来严肃，这类条目正是人性偶尔透光的地方。

它在如今 Bitcoin Core 界面上的实际效果：

- 所有显示的 BTC 金额（余额、各笔交易、手续费）被替换成 `*****` 之类的统一掩码。
- 当前会话内持续生效，直到你关掉它。
- 不改变钱包的任何真实状态；金额只是不渲染了。

入口在设置菜单，现代 Bitcoin Core 版本里通常叫「隐藏金额」或「隐私模式」（直白的「Lurking Wife Mode」字样在用户可见的标签里已被柔化，但功能和代号还在）。

局限：

- **防不住有心人。** 任何能碰你电脑的人，还是可以检查钱包文件或上链推导余额。
- **替代不了真正的隐私实践。** 地址轮换、CoinJoin、为不同身份分开钱包、硬件钱包、Tor 连接——那些才是真工具。老婆围观模式只是个防肩膀偷瞄的盾牌，仅此而已。
- **仅限 Bitcoin Core 的 GUI。** 其他钱包有各自的版本（常叫「余额隐私」「隐身模式」或就是个图标开关），范围各不相同。

文化脚注：这个功能有时被引用为证据，说明协议背后是一群会考虑比特币用户真实生活的人。同样功能的正襟危坐版（「隐藏钱包金额」）只是又一个菜单项；这个憨名字让它被记住，也让隐私功能背后的人味儿看得见。
