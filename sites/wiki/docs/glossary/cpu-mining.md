# CPU 挖矿（CPU Mining）

> **一句话定义：** 用电脑中央处理器挖矿，只在本宗极早期可行，GPU 与 ASIC 接管后已成历史。

CPU 挖矿是用通用电脑处理器而非专用硬件挖比特币。它是 2009–2010 年挖比特币的唯一方式，在比特币主网上经济性灭绝已超过十年。

历史进程：

- **2009–2010：** CPU 挖矿。任何有笔记本电脑的人都能找到区块。[中本聪](/glossary/satoshi-nakamoto)和 [Hal Finney](/glossary/hal-finneys-running-bitcoin) 就是这样挖的。
- **2010 年末：** GPU 挖矿兴起。显卡哈希比 CPU 快大约 50–100 倍，CPU 矿工无力竞争。
- **2013 年：** [ASIC](/glossary/asic-application-specific-integrated-circuit) 到来。GPU 矿工在数月内出局。
- **2014 年至今：** ASIC 独占时代。CPU 挖矿贡献的算力占比约为 0.000000001%，如果真有的话。

CPU 挖矿为何在文化中仍有一席（很小的）之地：

- **教育价值。** 对 testnet 或 regtest 跑 CPU 挖矿程序，是很多开发者第一次真正理解哈希是什么的途径。
- **彩票硬件。** 这些年里，少数人用廉价硬件 solo 挖中过主网区块——一个 U 盘矿机、一块家用 GPU、偶尔真有人用 CPU。概率天文数字般地小，但彩票属性吸引着一些爱好者。
- **某些山寨币仍偏好 CPU 挖矿**（如门罗的 RandomX）。那边的经济学不同。在比特币上，CPU 挖矿纯属情怀。

如果你在比特币主网上满负荷跑一年 CPU，预期出块数是小数点后一长串零的数字。你大概率会把办公室烘热、把电力供应商吓一跳，然后一块也找不到。[算力](/glossary/hash-rate)的数学不站在业余玩家一边。

2026 年真正能用的东西，见[矿机](/glossary/mining-rig)。
