# 削减负荷（Curtailment）

> **一句话定义：** 刻意削减或停止用电（或发电）以平衡电网。比特币挖矿是可削减负荷：电网需要电时，几秒内消失。

削减负荷是为了保持电网平衡而刻意减少用电或发电。电网上的供需必须逐瞬匹配；匹配不上时，总得有什么被削减掉。

它有两个方向，比特币挖矿两头都沾：

- **发电侧削减。** 风电或光伏发的电超过电网能用或能输的量时，过剩被削减——风轮顺桨、光伏限幅，能源直接浪费。这在可再生占比高、输电与储能有限的电网上经常发生。它是[弃置能源](/glossary/stranded-energy)的教科书案例：有电，无买家。
- **负荷侧削减。** 灵活的用电方按指令降低用电，让电网去服务更高优先级的需求。这是[需求响应](/glossary/demand-response)的那一侧。

## 为什么挖矿两头都合适

[矿工](/glossary/mining)是发电侧削减的最终买家——它愿意消耗风电场本来要浪费的过剩电子，因为那是能拿到的最便宜的电。它也是负荷侧削减的第一候选——电网需要容量回来时它能几秒关停，因为不像工厂，它损失的只是放弃的挖矿收入，而不是进行中的工作。

这种双向灵活性，就是挖矿反复出现在电网平衡论证里的原因。同一个属性——对电力*何时*流动无所谓——让矿工既能吸收没人要的电，也能交还人人突然要的电。
