# 托管钱包（Custodial Wallet）

> **一句话定义：** 第三方替用户保管私钥的钱包，如同银行代管客户资金。

托管钱包，是第三方握着[私钥](/glossary/private-key)、你拿着一个账户余额的钱包。Coinbase、Binance、Cash App、Robinhood——任何「你有 BTC」却从没见过助记词的服务，都是托管。

这句话的实际含义是：你并不拥有比特币。你拥有的是对比特币的**债权**——币在公司手里，记录在公司内部数据库里。公司有偿付能力又配合，这笔债权用起来和拥有比特币没两样；公司不是，那就不是。

托管方出事的频率，比加密圈营销愿意承认的高得多。Mt. Gox 2014 年丢了 85 万枚 BTC；QuadrigaCX 2019 年随 CEO 带走了钥匙；2022 年的连环爆雷在同一年内吞掉了 Celsius、BlockFi、Voyager、Genesis 和 FTX，仅 FTX 一家客户缺口就达 80 亿美元。客户清偿动辄数年，而且通常是部分清偿。

就算是正常运转的托管方，也能冻结你的账户、追加 KYC、在行情剧烈时限制提现，或者因为内部失守悄悄弄丢自己的热钱包私钥。这个风险模式是结构性的，不是杞人忧天。

「不是你的钥匙，就不是你的币」就是回应。它不是口号，是技术事实：比特币的核心属性——抗审查、抗没收、抗稀释的货币——只交付给真正握钥匙的人。其他任何人都只是在用一个手续繁多的银行。

托管钱包有正当用途：作为法币入场通道（总得从哪儿开始）、作为活跃交易场所、作为临时支付轨道。只是别把它和「拥有比特币」搞混。凡是真想留下的，转去自我托管（见[钱包](/glossary/wallet)、[硬件钱包](/glossary/hardware-wallet)）。
