# 冰山订单（Iceberg Order）

> **一句话定义：** 任何时刻只在订单簿上露出小一角、大头藏在水下的订单——露出的部分成交后，下一块自动浮现。

冰山订单是这样一种订单类型：任意时刻，只有订单的一小部分公开显示在交易所的订单簿上，其余全部隐藏。可见部分成交后，下一块自动显示出来。

运作方式：

1. 交易者下一笔冰山订单——比如以价格 X 买 100 BTC，可见规模 5 BTC。
2. 订单簿上只显示 5 BTC 那一片。
3. 这 5 BTC 成交后，撮合引擎自动在同一价位挂出下一块 5 BTC。
4. 如此继续，直到 100 BTC 全部成交（或交易者撤单）。

交易者为什么用它：

- **减小市场冲击。** 订单簿上明晃晃的 100 BTC 买单等于宣告大资金要买，大概率让市场朝对自己不利的方向动（卖方抬价、其他买方抢跑）。冰山结构藏住了总规模。
- **隐藏身份。** 巨鲸订单有人盯着。把大单拆成小的可见块，更难认出交易背后是谁。
- **改善成交质量。** 比起一口气吃穿多个价位的市价单，平均成交价更好。

哪里支持：

- **中心化交易所**：Coinbase Pro、Kraken、Binance、Bitfinex、OKX 及多数主流场所都提供冰山或「隐藏数量」订单，有时也叫「储备订单」。
- **衍生品市场**（CME、Bakkt）：冰山订单是标准的机构订单类型。
- **部分 DEX**：支持有限；链上机制让真正的隐藏订单很难实现。

代价：

- **排队优先级更差。** 多数交易所在同价位上把隐藏订单排在可见订单之后。你可能比全额可见的订单成交得更慢。
- **模式可探测。** 老练的做市商有时能从同一价位反复出现的等量补单里识别出冰山结构。藏得并不完美。
- **别人的反制。** 其他大交易者可能专门探测冰山流并与之对赌。猫鼠游戏永不停歇。

对普通交易者，冰山订单无关紧要——你的单子推不动市场。对机构资金流（OTC 柜台、大型基金、做市业务），它是执行大仓位而不泄露全貌的标准工具。
