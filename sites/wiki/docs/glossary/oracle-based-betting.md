# 预言机投注（Oracle-based Betting）

> **一句话定义：** 用谨慎日志合约（DLC）结算现实世界赌约：把对结果的证明交给外部预言机的签名。

比特币上的预言机投注用**谨慎日志合约（Discreet Log Contracts，DLC）**来结算对现实世界结果的赌注，赌客之间无需互信。信任被转移给**预言机（oracle）**——一个发布密码学签名、为结果作证的外部方。

DLC 赌约的高层流程：

1. **预言机事先公开承诺**一个公钥和一组可能的结果公告。（「选举日那天，我会在这些特定消息中的一条上签名：『结果 A』或『结果 B』。」）
2. **赌客构造一个使用预言机承诺的多签合约**，合约针对预言机的每种可能签名各有一个赔付分支。
3. **双方把资金锁进合约。**
4. **事件发生。** 预言机在真实结果上公布签名。
5. **任一赌客都可凭该签名**领取对应的赔付，合约自动结算。

有意思在哪：

- **预言机不需要知道合约的存在。** 它只需要公开承诺为事件结果签名。多个互不相关的赌约可以复用同一条预言机证词；预言机从不知道参与者是谁、金额是多少。
- **预言机无法单方面偷走资金。** 它只能影响结果的分布——而选哪个预言机来信任，是赌客自己的决定。
- **结算发生在比特币主链上**，除预言机的签名外，不需要任何托管中介或专门基础设施。

2026 年真实的 DLC 预言机生态：小但在增长。**Suredbits** 运营着最成熟的预言机基础设施（含 Krystal Bull 预言机工具和公共预言机浏览器）。**Lava Protocol** 用 DLC 做比特币抵押的稳定币贷款，有自己的 Pythia 预言机。**DLC.Link** 在搭建 DLC 与 Chainlink 的桥接基础设施。另有一些小型体育和选举预言机公开运营。相对传统博彩市场，DLC 活动仍属小众，但底层技术已是生产就绪。

隐私优势也是真实的：从链的角度看，一笔 DLC 结算就是一次普通的 [Taproot](/glossary/taproot) 花费，与常规协作花费无从区分。赌局、赛果、选举预测——全部在链上结算，而不透露它们是什么。
