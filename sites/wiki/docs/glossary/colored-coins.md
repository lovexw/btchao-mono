# 彩色币（Colored Coins）

> **一句话定义：** 2012–2014 年「在特定聪上打标记来表示外部资产」的原始构想——聪明但没跑起来；今天一切比特币代币实验的老祖宗。

彩色币（colored coins）是最初的（2012–2014 年）构想：用链下元数据给特定的聪「上色」，从而在比特币上表示任意资产。原理是：宣布某个 UTXO 代表一项资产（一股股票、一份产权、一种货币），由一个平行的链下账本追踪哪些 UTXO 带什么颜色。

原始设计很聪明，但没真正跑起来，原因有这几个：

- **链上不强制。** 比特币协议分不出「蓝色聪」和普通聪。颜色规则完全活在链下的客户端软件里。
- **碎片化风险。** 颜色元数据一旦丢失、或不同客户端对上色规则有分歧，同一个 UTXO 在不同观察者眼里就是不同的东西。
- **混合问题。** 上色的 UTXO 与普通 UTXO 一起花费时，哪个输出继承颜色就成了悬案。
- **吞吐量限制。** 每笔彩色币交易就是一笔普通比特币交易，链上成本一分不少。

后继与衍生：

- **Counterparty**（2014，基本已成历史）。把资产数据嵌进 OP_RETURN 输出，承载过早期代币实验。
- **Omni Layer**（2014 至今）。最初在比特币上发行了 USDT（如今 USDT 的大头已迁往以太坊 / 波场）。
- **RGB 与 Taproot Assets**（2022 起）。利用 Taproot 和客户端侧验证的现代复活的思路。开发活跃，生产使用有限。
- **铭文 / Ordinals / Runes / BRC-20**（2023 起）。当前这波「万物皆代币」实验，把数据嵌入见证空间和按序数编号的聪。社区里争议很大；2023–2024 年费率尖峰期间商业上举足轻重。

2026 年的现实：彩色币式的比特币代币仍是实验性的小众品。代币活动的大头发生在以太坊、Solana 等智能合约链上。持久的吸引力在于「在最安全的结算层上结算代币」，但现实（手续费、复杂度、对同质性的影响）把大多数代币活动挡在比特币之外。诚实的评价：比特币能承载代币，但它不为此优化，多数用例在别处更好，或者根本不成立。
