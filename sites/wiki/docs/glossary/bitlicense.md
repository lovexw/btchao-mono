# BitLicense

> **一句话定义：** 纽约州金融服务局 2015 年推出的虚拟货币业务牌照——全球最早的辖区级加密监管框架之一，也以要求苛刻闻名。

BitLicense 是纽约州金融服务局（NYDFS）颁发的州级虚拟货币牌照。2015 年推出，是全球最早的辖区专属加密监管框架之一，其苛刻程度也出了名。

持牌方要承诺什么：

- **KYC / AML。** 对客户做完整身份验证、持续交易监控、可疑活动上报。
- **网络安全。** 详尽的制度文档、定期审计、正式的事件响应预案。
- **资本与保证金。** 维持最低资本储备；某些业务还需履约保证保险。
- **消费者保护。** 披露义务、投诉处理流程、对特定行为的限制。
- **报告。** 季度财务报告，重大变更随时加报。

申请流程以又慢又贵著称：申报的法律与合规成本高达数十万美元。牌照本身只授权在纽约州经营；服务其他美国州的业务还得分别搞定各州的资金传输牌照。

面向纽约开展业务的美国主流加密公司多数持有 BitLicense（或在有限的豁免下运营）：Coinbase、Gemini、Circle、Paxos、Bitstamp 等。另一些干脆只对非纽约居民开放——「您所在州暂不提供服务」那个模式。Kraken 的选择最出名：直接把主要服务撤出纽约，拒绝申请，理由是成本收益比不划算。

BitLicense 至今是个有争议的框架。辩护方说它在一个欺诈横行的市场里提供了消费者保护（NYDFS 确实也对作恶者执法）；批评方说它让资金雄厚的在位者占优、把小竞争者挤出市场、把创新推向别的辖区。两边都有证据。
