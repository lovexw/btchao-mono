# 出清价格（Clearing Price）

> **一句话定义：** 买卖订单交汇成交的市场均衡价——交易所上跳动的那个数；被引用最多、也最依赖语境的比特币指标。

出清价格是买卖双方订单交叉成交的市场均衡点：在这个价上，愿意买的人和愿意卖的人真实成交了。交易所上跳动的就是它：「BTC/USD 报 X 美元」即当前出清价格。

机制上，在一个连续订单簿交易所里：

- **买方（bid）**是买单队列，价高者排前。
- **卖方（ask）**是卖单队列，价低者排前。
- **出清价格**就是最高买价与最低卖价相遇（或交叉）之处。交叉即成交，订单簿随之更新。

这是实时进行的价格发现机制。有几件事让画面变复杂：

- **多家交易所、价格略有差异。** 套利资金抹平差距但不消灭差距。Coinbase、Kraken、Binance、Bitfinex、Bitstamp 通常只差几个基点；小场所可能明显偏离。
- **OTC 柜台与大宗交易**在公开订单簿之外按协商价出清，价格有时与公开出清价差得不少——毕竟那种体量砸进可见订单簿会自己推动价格。
- **本地法币交易对**（人民币、印度卢比、尼日利亚奈拉、阿根廷比索等）对美元价可能呈现大幅溢价或折价，反映资本管制与套利摩擦。

对用户来说，「比特币的价格」通常指主要美元交易所按成交量加权的合并中间价。CME CF 比特币参考汇率、Coinbase 的价格指数、Coingecko 之类的指数源替下游消费者聚合这个数。

出清价格是被引用最多的比特币指标，也是对语境依赖最重的指标。它是好用的每日参照，却回答不了「比特币值多少」——那要看规模、场所和时间跨度。
