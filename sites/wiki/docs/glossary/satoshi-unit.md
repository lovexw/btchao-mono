# 聪（Satoshi）

> **一句话定义：** 比特币最小单位：1 聪 = 0.00000001 BTC（1 亿聪 = 1 BTC）。

聪（satoshi，简称 sat）是比特币的最小单位。**1 BTC = 100,000,000 聪。** 聪以下没有了——在链上，比特币不能再细分（[闪电网络](/glossary/lightning-network)内部为了更精细的路由用毫聪记账，但那只存在于二层，基础链上没有这个东西）。

以[中本聪](/glossary/satoshi-nakamoto)命名的聪，是协议层的整数单位。Bitcoin Core 内部所有余额和金额都以聪计；「BTC」只是把聪的数目除以 1 亿之后的人类可读写法。

在 2026 年的钱包文化里，聪正越来越成为日常谈「币」的默认单位：

- **闪电网络余额**几乎一律以聪显示。
- **费率**永远以每虚拟字节多少聪（sat/vB）报价。
- **囤币文化**把「stacking sats」（一聪一聪地攒）当作积累 BTC 的标准说法。
- **打赏和小额支付**以聪计价——「1,000 聪」远比「0.00001 BTC」可读。
- **Nostr zaps**（跑在闪电网络上的打赏）完全用聪报价。

一个有用的心智锚点：当 BTC 价格到 100 万美元（不少人预期一二十年内会看到）时，**1 聪 = 0.01 美元**，聪就顺理成章成了比特币的日常「分币」。这种收敛，正是聪越来越成为自然单位的原因——哪怕你根本不玩闪电网络。
