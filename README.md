# 比特币大事记网站

一个专业、客观、易读的比特币历史时间线网站，记录从比特币诞生到现在的完整发展历程。

## 🎯 项目目标

- **时间线可视化**: 清晰展示比特币发展的关键节点
- **结构清晰**: 按时间顺序和主题分类组织内容
- **面向大众易懂**: 使用简洁明了的语言解释复杂概念
- **保持中立记录**: 客观记录历史事实，不夸大、不煽动

## 📁 项目结构

```
bitcoin-timeline/
├── index.html          # 主页面文件
├── styles.css          # 样式文件
├── data.js            # 比特币历史数据
├── script.js          # 页面交互逻辑
└── README.md          # 项目说明文档
```

## 🚀 功能特性

### 📊 主要内容模块

1. **概览**: 比特币发展的关键数据统计（创世、供应、价格历程、算力、国家采用、中国市场、减半倒计时）
2. **时间线**: 完整的历史事件时间线（2008-2026，约170条）——全站唯一事实来源，其余板块均为主题视角
3. **重要里程碑**: 2008-2026按年份分类的关键事件（19年全覆盖）
4. **技术升级详解**: 协议与升级的技术档案（BIP编号、激活区块、解决的问题，共13条）
5. **价格历史**: 价格变化的重要节点（从$0.00076到$126,200，43个节点，含1/10/100/1k/10k/20k/50k/100k美元等全部里程碑，附人民币参照）
6. **爆仓大事件**: 单日全网爆仓≥10亿美元的20个历史时刻（按金额降序，每条写清引爆原因→价格路径→为何爆仓巨大的完整因果链）
7. **中国视角**: 中国市场、华人与香港（13张专题卡片 + 从时间线自动聚合的"中国足迹"列表）
8. **挖矿历程**: 从CPU到1 ZH/s的完整挖矿发展史
   - 经典矿机发布（Avalon、蚂蚁S1/S3/S7/S9/S17/S19/S21系列、神马M20S/M50等）
   - 挖矿难度里程碑（1到140T+的完整记录）
   - 算力迁移事件（中国禁矿等）与矿业AI转型
9. **政策监管**: 中美欧日港等政策演变
   - 中国监管历程（2013首次监管→2017"九四"→2021"九二四"全面禁止）
   - 美国政策发展（FinCEN→IRS→ETF获批→战略储备→GENIUS/CLARITY立法）
   - 其他国家与地区政策（萨尔瓦多法币、欧盟MiCA、日本合法化、香港VASP与稳定币条例）
10. **安全事故**: 重大漏洞与黑客事件（23条+累计统计卡）
   - 协议漏洞（1844亿BTC溢出漏洞、CVE-2018-17144等）
   - 交易所被盗（Mt.Gox 85万、Bitfinex 12万、Sheep 9.6万、Zaif、Poloniex、DMM、Bybit 14.6亿美元等）
   - 钱包与侧链（2026 Coldcard固件熵缺陷、Liquid Network侧链攻击）
   - 执法追回（Bitfinex 94,000枚史上最大追回案）
   - **累计估算卡**：史上被盗比特币约130万-140万枚（含追回）/净损失约95万-110万枚，占2100万上限的4.5%-6.7%

## 📅 时间线覆盖范围

### 创世时期 (2008-2010)
- 白皮书发布、bitcoin.org注册、创世区块、首笔交易
- 首个汇率（1美元=1,309枚）、首个交易所、披萨日
- Slashdot暴涨、Mt. Gox上线、1844亿枚溢出漏洞、首个矿池
- GPU挖矿开启、中本聪淡出

### 早期发展 (2011-2013)
- 价格首破1/10/100/1000美元（含31.9美元泡沫与94%崩盘）
- 交易所兴起（Mt. Gox闪跌、BTCC成立、MyBitcoin倒闭）
- 第一次减半、ASIC矿机诞生（Avalon、蚂蚁S1）
- BIP32/BIP39标准提出、丝绸之路查封、首台ATM
- 中国首次监管（五部委通知）

### 成长期 (2014-2016)
- Mt. Gox破产（85万枚失踪）、IRS税务指引、BitLicense
- Coinbase/Gemini持牌交易所上线、欧盟VAT豁免
- 第二次减半、技术升级（BIP65、SegWit提案）
- Bitfinex被盗12万枚、经典矿机S9发布

### 繁荣期 (2017-2020)
- 扩容大战与分叉（BIP91、BCH、SegWit激活）
- 价格历史新高（19,783美元）、中国禁止ICO和交易所
- CME/CBOE期货、闪电网络、富达入场
- 3·12暴跌、第三次减半、机构入场（MicroStrategy、PayPal）、突破2万美元

### 主流化 (2021-2024)
- 历史最高价69,044美元、Coinbase上市
- 中国全面禁止挖矿（算力迁移、难度暴跌28%）
- 萨尔瓦多法币采用、Taproot升级
- Terra/FTX连环暴雷与15,480美元大底
- Ordinals铭文、贝莱德ETF申请、现货ETF获批（2024）
- 第四次减半、第四次区块奖励3.125枚
- 特朗普胜选与历史性突破100,000美元（2024-12-05）

### 政策与周期 (2025-2026)
- 战略比特币储备行政令、GENIUS/CLARITY立法、401(k)开闸
- 历史最高约126,200美元（2025-10-06）与『10·11』193亿美元爆仓
- Ulbricht/CZ赦免、Bitcoin Core 30治理争议
- 2026年熊市：2月单日-12.6%、7月低点57,750美元（-54%）
- 全网算力首破1 ZH/s、Strategy首次卖币、美联储重启加息
- CLARITY参议院搁浅（2026-09-15）
