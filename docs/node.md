> 「不验证，勿信任」的最后一环，就是亲手验证。本章是[第 6 章 · 主权](/journey/sovereignty)的独立实操版——只想查资料的老手可以直接照做。

## 为什么值得跑一个节点

- **验证一切。** 自己的节点从创世区块开始核对每一条规则、每一笔交易。「我的余额」不再来自任何人的转述。
- **隐私归零泄露。** 你的钱包查询的是你自己的机器，没有任何第三方看得到你关心哪些地址。
- **抗审查。** 依赖公共服务的钱包可以被服务方切断；连自己节点的钱包不会。
- **支撑网络。** 全节点越多，比特币越去中心化。跑节点不赚钱，报酬就是系统本身。

成本：几百 MB 内存 + 整条链的磁盘（2026 年约 700 GB，年增约 50 GB）+ 初次同步的一两天等待。之后就基本不用管了。

## 硬件怎么选

| 方案 | 成本 | 适合 |
| --- | --- | --- |
| 树莓派 5 + 1 TB SSD | 约 $200 | 低功耗 7×24，经典选择 |
| 翻新迷你主机（NUC 类） | $150–300 | 以后想跑闪电网络或别的自托管服务 |
| 闲置笔记本/台式机 | 免费 | 硬件还凑合、不想花钱 |

## 软件怎么选

| 方案 | 特点 | 适合 |
| --- | --- | --- |
| [Umbrel](https://umbrel.com) | Web 界面 + 应用商店，一键安装 | 新手，要体验顺滑 |
| Start9（StartOS） | 主权导向，隐私与 Tor 默认更严 | 在意默认隐私的人 |
| [Bitcoin Core](https://bitcoincore.org) 直装 | 无封装，自己写 `bitcoin.conf` | 习惯命令行、要零抽象 |

## 部署六步

1. **烧录系统** 到 SSD（balenaEtcher / Rufus / `dd`）。
2. **开机连网**，浏览器打开节点管理界面（Umbrel/Start9 会在局域网给出 `.local` 地址）。
3. **等初次同步**：下载并验证整条链，视硬件一到数天。放着别动。
4. **开 Tor**（节点系统里通常是个开关）。
5. **验证节点工作**：查最新区块高度、按 ID 查一笔交易、查一个地址余额。
6. **把钱包指过来**：Sparrow / Electrum / Specter 都支持填入自己的节点或 Electrum 服务器地址——一次性配置（详见[第 6 章第 5 节](/journey/sovereignty#_5-把钱包指向你的节点)）。

## 常用 RPC 速查

节点同步完成后，这些命令可以直接用（`bitcoin-cli`）：

```bash
bitcoin-cli getblockchaininfo        # 链状态、同步进度、区块高度
bitcoin-cli getblockcount            # 当前区块高度
bitcoin-cli getrawmempool | wc -l    # 内存池交易数量
bitcoin-cli gettransaction <txid>    # 查一笔交易（钱包相关）
bitcoin-cli getblockstats <高度>      # 某区块的统计信息
bitcoin-cli estimatesmartfee 6       # 6 个确认内的建议费率
```

想看更直观的实时全网数据（内存池、费率、出块倒计时），用 [mempool.space](https://mempool.space)——它本身也是开源项目，你可以把它连到自己的节点上自建。

## 常见问题

**同步太慢？** 买好一点的 SSD 是第一杠杆，其次是保证节点 7×24 在线不中断。

**多大硬盘够？** 当前约 700 GB，预留 1 TB 可以安心用三四年。

**跑节点赚钱吗？** 不赚。它增强的是*你自己*的验证能力与整个网络的去中心化，这不是一个生意，是一种立场。

**需要固定 IP / 公网吗？** 不需要。出站连接就够；开了 Tor 更无需暴露任何端口。
