# 竞争性挖矿（Competitive Mining）

> **一句话定义：** 比特币挖矿的开放性：任何有 ASIC 和电力的人都可以来竞争发现有效区块。

竞争性挖矿是比特币工作量证明的无许可本质：不需要执照，没有最低门槛，协议层面不做任何歧视。任何买到 ASIC 和电力的人都可以哈希，每个区块的赢家纯粹由谁先找到有效随机数决定。

这场竞争优化什么：

- **每块钱买到的算力。** 新代际 ASIC（蚂蚁 S21、Whatsminer M60、S21 XP 等）每瓦特产出更多算力。机群更新很快；两三年机龄的 ASIC 在当前难度下通常已不经济。
- **电价。** 挖矿经济的主导变量。盈利的运营每 kWh 付 3–5 美分；7–8 美分以上就是边缘。这就是挖矿聚集在弃置水电、火炬天然气、核电基荷和闲置电网容量旁的原因。
- **运营效率。** 散热（浸没或水冷）、设施可用性、固件调优、[第三方固件](/glossary/proprietary-mining-firmware)、矿池选择。规模化之下，每个百分点都算数。

去中心化的故事是喜忧参半的。挖矿原则上无许可，但实践中资本密度（工业设施、ASIC 供应链、便宜电力合同）把挖矿集中到资本雄厚的运营者手里。矿池这层则即使底层矿工分散，也进一步聚合算力。诚实的账本见[挖矿中心化](/glossary/mining-centralization)。

尽管如此，结构性属性依然成立：协议不选赢家。一个带着 ASIC 和便宜电力的新玩家可以加入、挖矿、收款、退出，无需任何人点头。这就是竞争性挖矿提供的去中心化地板。
