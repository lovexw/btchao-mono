# 中心化交易所（CEX）

> **一句话定义：** 一家公司同时当托管人、订单簿和撮合引擎——好用、流动性高，但你的余额只是对比特币的「索取权」，不是比特币本身。

中心化交易所（CEX）是一家同时扮演托管人、订单簿和撮合引擎角色的公司：Coinbase、Binance、Kraken、Cash App，以及一长串长尾。你存入 BTC，他们保管；你在他们的内部账本上交易；他们允许的时候，你可以提走。

CEX 擅长什么：

- **流动性。** 头部 CEX 日撮合数亿到数十亿美元，大额买卖也不会显著推动价格。
- **法币出入金。** 银行转账、借记卡等出入金基础设施，去中心化替代品给不了。
- **用户体验。** 打磨过的 App、客服、与其他金融服务的整合。
- **交易功能。** 限价单、期货、期权、杠杆——整套传统金融工具箱。

CEX 不是什么：

- **不是你该存放「真正想拥有的比特币」的地方。** CEX 余额是对比特币的*索取权*，不是比特币本身。交易所的偿付能力、托管操作、监管处境，全都横在你和你的钱之间。

CEX 暴雷的历史又长又新鲜：Mt. Gox（2014）、QuadrigaCX（2019）、Celsius/BlockFi/Voyager/Genesis（2022）、FTX（2022）。仅 2022 年的连环传染病就蒸发了数百亿美元客户余额。更大的图景见[对手方风险](/glossary/counterparty-risk)。

务实做法：CEX 是有用的入场通道。用它把法币换成 BTC，任何有意义的金额都提币到自托管[钱包](/glossary/wallet)（理想是[硬件钱包](/glossary/hardware-wallet)）。别把交易所余额当储蓄。

非托管的替代方案见[去中心化交易所（DEX）](/glossary/decentralized-exchange-dex)。
