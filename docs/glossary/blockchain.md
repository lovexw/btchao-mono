# 区块链（Blockchain）

> **一句话定义：** 用密码学哈希把交易批次（区块）串成的分布式账本，数据历史防篡改。

构造本身很简单：每个区块在自己的头部写入上一个区块头部的 SHA-256 [哈希](/glossary/hash)。于是第 800,000 号区块用哈希引用第 799,999 号，后者再引用 799,998 号，一路回到[创世区块](/glossary/genesis-block)。改动任何历史区块的一个字节，它的哈希就变，之后每个区块引用的「父哈希」就全错，此后所有区块都要重新挖。以比特币[工作量证明](/glossary/proof-work-pow)的负担计，代价极快地变得不可能。

每个全节点存储整条链——目前约 600 GB，每年增长约 150 GB——并独立地按每一条共识规则验证每一个区块。没有「总账」这回事：存在的是几万份相同的副本，彼此互为校验。想改写比特币的历史，你得说服这些节点中的多数接受你的假版本。它们不会。

「区块链」一词后来被泛指一切「只增不改、哈希相连」的数据结构，被拴上过无数可信度参差的项目。比特币的区块链才是要紧的那个：第一个、最大、最安全，也是唯一真正解决了它被设计要解决的问题的那个。

为什么这条链这么难改写，见[挖矿：算力、难度与激励](/rabbit-holes/mining)；每一环里装着什么，见[区块](/glossary/block)。
