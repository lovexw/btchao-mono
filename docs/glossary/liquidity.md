# 流动性（Liquidity）

> **一句话定义：** 市场语境下指买卖 BTC 而不明显推动价格的难易；闪电网络语境下指通道的可用容量。

「流动性」在比特币的市场语境和闪电网络语境里是两个不同的意思。两个都重要；把它们混为一谈会乱成一锅粥。

**市场流动性**关乎交易所的订单簿和场外市场：你最多能买/卖多少而不推动价格。流动性高意味着买卖价差紧、大单可以无滑点成交、价格发现过程稳健。流动性低意味着订单簿薄、价差大、稍大的成交量就能把价格甩来甩去。BTC/USD 的主要交易所现货市场流动性极深（日成交数十亿美元、价差不到一分钱）；小平台或冷门交易对则不然。

**闪电流动性**关乎通道余额的分布。每条闪电通道的总容量（注资输出里的金额）分成两部分：本地余额（你的，可用来发送）和远程余额（对端的，可用来发给你，也就是你的入站容量）。

- **出站流动性。** 通道在你这一侧的余额，可以用来发送支付。
- **入站流动性。** 通道在对端一侧的余额，别人可以借此付钱给你。你新开一条自己出资的通道，入站流动性是零——余额流进来之前你收不到任何钱。

入站流动性不够的闪电用户，收不到超过远程侧现有余额的支付。出站不够的用户发不出钱。路由节点需要[平衡通道](/glossary/balanced-channel-lightning)（两侧都有相当流动性）才能双向转发。

获得入站流动性的办法：

- 先把出站花掉（你发出的每笔支付都把余额推向对端，增加你的入站）。
- 向路由节点服务购买入站（[流动性广告](/glossary/liquidity-ads)、Lightning Labs 的 Pool 等），或通过非托管的潜水艇互换（[Loop In/Out](/glossary/loop-inout)）再平衡。
- Splice 出资开新通道，或由对端出资开通道。
- 通过收款赚取入站（但如果你本来就收不到款，这就成了死循环）。

这种不对称是闪电网络挥之不去的 UX 难题之一。新用户第一次尝试收款就撞上入站流动性的墙，还不知道为什么。
