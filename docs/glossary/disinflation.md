# 通胀减速（Disinflation）

> **一句话定义：** 通胀率随时间下降。比特币的发行率随每次减半减半，是程序化通胀减速的教科书案例。

通胀减速（disinflation）的意思是，通胀还在发生，但发生得*越来越少*。价格或货币供应仍在上涨，只是涨速在放缓。

比特币是货币史上最干净的程序化通胀减速案例。每个区块都会铸造新 BTC，所以流通供应量在持续增长——但每 210,000 个区块（约 4 年），单区块发行量被砍半。于是通胀率以离散的台阶逐级下降：

- **2009–2012：** 每区块 50 BTC 补贴
- **2012–2016：** 每区块 25 BTC（第一次减半后）
- **2016–2020：** 每区块 12.5 BTC
- **2020–2024：** 每区块 6.25 BTC
- **2024–2028：** 每区块 3.125 BTC（当前，年通胀约 0.83%）
- **2028–2032：** 每区块 1.5625 BTC（通胀约 0.4%）

每 210,000 个区块重复一次，直到补贴在 2140 年前后归零。从那以后，比特币的货币通胀为零——矿工的全部收入都来自交易手续费。

通胀减速与法币系统的常态恰恰相反。央行通常*主动瞄准*一个正的通胀率（美联储目标是 2%）。比特币不瞄准任何通胀率，并以渐近线的方式趋向于零。
