# 区块奖励（Block Reward）

> **一句话定义：** 矿工找到有效区块获得的全部报酬，等于区块补贴加交易手续费。

区块奖励是矿工找到有效区块拿到的全部报酬。它有两部分：

1. **[区块补贴](/glossary/block-subsidy)** ——新发行的 BTC，目前每块 3.125 枚，每 210,000 块减半一次，直到 2140 年前后归零。
2. **交易手续费** ——矿工选择打包进区块的每笔交易的手续费之和。不固定，取决于内存池行情。

两部分都通过 [Coinbase 交易](/glossary/coinbase-transaction)——每个区块里特殊的第一笔交易——付给矿工。早年补贴几乎就是奖励的全部（交易基本免费）。如今手续费通常占 3–10%，内存池拥堵时偶尔冲高。

比特币安全性的长期经济问题是：手续费能否完全取代不断缩水的补贴。到目前为止，趋势与设计一致——随着比特币的使用成熟，每字节费率持续走高。长版本见[挖矿：算力、难度与激励](/rabbit-holes/mining)。
