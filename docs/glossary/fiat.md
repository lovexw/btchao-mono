# 法币（Fiat）

> **一句话定义：** 由政府法令赋予价值的货币——美元、欧元——没有实物商品背书，价值完全依赖国家权威与信任。

法币是靠政府法令而非任何实物背书宣布其价值的货币。美元、欧元、日元，都是法币。金库里没有黄金可以兑付它们；它们的价值完全建立在法定货币法和人们对发行央行的信任上。

法币有比特币没有的两项超能力。其一，国家权威可以强迫人们接受它——试试用 BTC 缴美国的税。其二，发行方可以随时造出更多。第二项超能力也正是法币在数十年的尺度上必然损失购买力的原因：美元相对 1913 年的价值已跌去约 96%；阿根廷比索在不到十年里跌掉了 2018 年价值的 99% 以上。

比特币就是作为它的直接对立面被设计的：没有发行方、没有相机抉择的政策、供应量固定。这不等于法币明天就消失。地球上大多数人领法币工资、用法币交房租，再通过「法币入金通道」——交易所、ATM 或点对点交易——换成 BTC。两套系统并存。比特币的角色，是做那个不会被稀释的选项。
