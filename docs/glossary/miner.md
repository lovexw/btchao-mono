# 矿工（Miner）

> **一句话定义：** 用专用硬件寻找有效区块哈希的参与者：保护网络安全，赚取区块奖励。

矿工是任何运行硬件参与比特币[工作量证明](/glossary/proof-work-pow)的人——生成候选[区块头](/glossary/block-header)并反复哈希，试图找到一个有效到可以向全网提议的区块。作为回报，矿工收取[区块奖励](/glossary/block-reward)：新发行的 BTC，加上所打包交易的全部手续费。

如今实践中，「矿工」多为大型工业运营：跑着成千上万颗 ASIC 芯片，选址在便宜电力旁（雨季的四川水电、西得克萨斯的弃置天然气、冰岛的地热、法国的低谷核电）。硬件是专用的，经济性薄如刀刃，每千瓦时电价决定生死。

小玩家依然存在。单机双机的 solo 矿工偶尔靠「彩票硬件」中签。爱好者为了体验跑小矿机。不过，大部分生产算力都流经[矿池](/glossary/mining-pool)——把小贡献者捆绑起来、让每人获得平滑 payouts 而不是苦等数年一签的聚合者。

矿工不是比特币的统治者。协议由每个全节点执行，而不是矿工。矿工可以选择在自己区块里*打包哪些有效交易*，但改不了规则。任何违反共识的区块（超过允许的补贴、无效签名等）都会被地球上每个诚实节点拒绝。

完整机制见[挖矿：算力、难度与激励](/rabbit-holes/mining)，矿工实际如何组织带来的中心化问题见[矿池](/glossary/mining-pool)。
