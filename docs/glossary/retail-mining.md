# 家用挖矿（Retail Mining）

> **一句话定义：** 家中小规模挖矿，ASIC 时代基本被工业运营盖过风头。

「家用挖矿」是在家里或小型场地做的小规模比特币挖矿，通常一台或几台 [ASIC](/glossary/asic-application-specific-integrated-circuit)。大约 2014 年工业挖矿接管以来，它的经济性一直处于边缘；但 2024–2026 年，一些具体的顺风让它悄悄复兴。

2026 年家用挖矿对部分玩家可行的原因：

- **热量再利用。** 一台矿机持续产出 3–4 kW 的热。在寒冷气候里这就是免费取暖——等于用本来就要花在取暖上的电「付了」买 BTC 的钱。Bitmain 的 Antminer Hydro 系列和独立的「取暖器」形态正是瞄准这个市场。
- **离网能源。** 弃置的可再生能源（乡村光伏、风电、小微水电）可以在不并网的情况下给矿机供电。产出的 BTC 本质上是对「否则会被削减的能源」的变现。
- **算力定投。** 一些人把家用挖矿看作「用电费账单做定投」——定期小额积累 BTC，而不是指望逐日盈利。
- **彩票挖矿文化。** 廉价的「彩票」矿机在家 solo 跑，期望收益微不足道，但有一个非零的机会挖中一个约 3.125 BTC 的区块。真有人中过；这些故事支撑着这个流派。

依然行不通的：

- **纯逐利的家用挖矿**，用普通民用电价（通常 $0.10–0.30/kWh）与工业运营竞争。$0.04–0.07/kWh 的工业挖矿碾压你。
- **民用电价上的老硬件。** 一台两年机龄、25 J/TH 的矿机在 $0.15/kWh 的电价上，还没算折旧就已经亏钱。

家用挖矿不会主导全球算力，但可能在边缘扮演真实角色——取暖经济里、离网场景里，以及「我跑自己的矿机」这句话的文化底气。这是比整个产业小的故事，但不是假故事。
