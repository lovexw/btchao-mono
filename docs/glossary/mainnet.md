# 主网（Mainnet）

> **一句话定义：** 比特币的主网络：真实 BTC 在这里流转、挖矿奖励有真实经济价值的链。

主网（mainnet）就是比特币网络——真实 BTC 流动、真实价值处于风险之中、每个区块都接在 2009 年 1 月 3 日[创世区块](/glossary/genesis-block)之后的那条链上。

你「使用比特币」时，用的就是主网。你「运行比特币节点」时，除非明确配置了别的网络，跑的就是主网节点。你在本站读到的算力、供应量、手续费，凡是数字，说的都是主网。

主网与其他网络的区别：

- **真实的经济价值。** 主网上的 BTC 有市场价格，这里的 bug 和失误都是真金白银。
- **真实的工作量证明。** 主网由约 700 EH/s 的算力保护；其他比特币协议网络的算力只是零头，面对攻击算力毫无实质防御。
- **严格的共识规则。** 主网运行 Bitcoin Core 的全部共识规则，没有任何放宽。一些测试网络允许为实验放宽规则。

其他比特币协议网络是为开发者与实验而生的：

- **[测试网（Testnet）](/glossary/testnet)**——公开的开发网络，币没有价值。
- **[Signet](/glossary/signet)**——更稳定的测试网络，由区块签名者协调出块。
- **Regtest**——私有的本地网络，按需出块，用于测试。

这些都不是主网。它们各自使用不同魔数的创世区块，链之间不可互通。为测试网配置的钱包发不到主网地址——网络 ID 对不上。

如果你在 2026 年学比特币，有人让你打真 BTC 去测试什么——你就在主网上。小心。
