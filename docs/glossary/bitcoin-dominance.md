# 比特币主导率（Bitcoin Dominance）

> **一句话定义：** BTC 市值占加密货币总市值的百分比——被广泛追踪的情绪仪表盘。

比特币主导率（Bitcoin Dominance）是比特币[市值](/glossary/market-capitalization)占加密货币总市值的百分比。若 BTC 市值 2 万亿美元、加密总市值 3.3 万亿美元，主导率约 60%。

这个数字被广泛当作情绪指标追踪：

- **主导率上升**通常意味着资金流向比特币、离开[山寨币](/glossary/altcoin)。见于熊市（奔向相对优质资产）、牛市早期（比特币先动）、宏观压力事件。
- **主导率下降**通常意味着资金轮动进山寨币。见于周期末的狂热、[山寨季](/glossary/alt-season)、散户投机高涨期。

历史脉络：

- **2013 年：** 主导率约 95%。尚无有分量的山寨币。
- **2018 年 ICO 顶点：** 主导率短暂跌破 35%。山寨币第一次整体与比特币分庭抗礼。
- **2020–2021 周期：** 主导率在 40–70% 之间震荡。
- **2024–2026 年：** 总体重心上移（约 50–65%），FTX 之后的出清浇灭了山寨热情。

对这个指标的几句实话：

- **「加密总市值」细看是虚构的。** 很多山寨币有巨大的内部人份额或近乎为零的流动性，它们的市值是纸面数字。比特币的市值也是纸面的，但底层资产至少在全球的真实流动性里交易。
- **主导率依赖口径。** 今天算「其余加密」的东西（含 USDT/USDC 等稳定币）和 2017 年算的不一样，跨长时段比较有噪声。
- **比特币极大主义者会主张主导率本该永远约等于 100%**，因为其他一切在某种技术或道德意义上都不算钱。这是一种观点；指标本身不站队。

对交易者，主导率是情绪表盘。对长期持币者，它多半只是个趣闻。
