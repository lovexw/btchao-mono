# 可替代性（Fungibility）

> **一句话定义：** 货币的任一单位可与任何其他单位互换、不带「身份」或历史的性质。

可替代性指的是：货币的任何一个单位都能与任何其他单位互换。你钱包里的一美元和收银机里的一美元是同一美元；没人问它从哪儿来。

比特币*在协议层*是可替代的：1 BTC 永远等于 1 BTC，共识规则从不按历史区分币与币。但比特币同时又是完全*透明*的——每笔交易永远公开可见，这意味着币可以被追溯到过去的活动，包括非法活动。链上分析公司利用这一点，一些交易所或交易对手可能拒收与黑客、勒索软件或受制裁地址相关的币。这个现实侵蚀着纯粹的可替代性。

有几种工具在反击。[CoinJoin](/glossary/coinjoin) 把许多用户的输入合并进一笔交易，切断交易图上的关联。[静默支付](/glossary/silent-payments)与[隐形地址](/glossary/stealth-address)减少链上地址复用。[闪电网络](/glossary/lightning-network)把支付路由到链下，不再逐笔广播。

更深一层的论点是：可替代性是一个必须由社区去守护的属性，而不只是协议强制执行的属性。协议阻止不了第三方给某些币打上「污点」标签。比特币人可以——拒绝接受这种叙事框架，并把隐私工具当日常默认用起来。一种币有记忆的货币，最终会变成一种币要许可的货币。

交易所的风险评分如何在实践中侵蚀可替代性，见[比特币隐私专题](/rabbit-holes/bitcoin-privacy)。
