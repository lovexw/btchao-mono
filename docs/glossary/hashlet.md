# Hashlet

> **一句话定义：** GAW Miners 2014 年兜售的「云挖矿份额」——比特币史上最著名的骗局之一。

「Hashlet」是 GAW Miners 于 2014 年销售的比特币云挖矿产品的品牌名。它也是比特币历史上最臭名昭著的骗局之一，是一个关于「不丢私钥也能在比特币上亏钱」的绝佳反面教材。

推销话术：

- GAW Miners（Josh Garza 创立）出售「Hashlet」——号称是对其挖矿业务的分数所有权份额。
- 每个 Hashlet 宣称给你 GAW 算力的一部分，每日分红。
- 产品 2014 年 8 月上线；数万个 Hashlet 售出，总收入超 1,000 万美元。

问题所在：

- GAW 宣称运营的挖矿硬件，要么达不到声称的规模，要么根本不存在。
- 所谓「分红」，是拿后来投资人的钱付给早期投资人。教科书级旁氏结构。
- GAW 还发行了「Paycoin」（XPY），Garza 承诺该币由 1 亿美元的「Coin Vault」背书。金库不存在。Paycoin 从峰值 14 美元在数月内崩至归零。

结局：

- 2015 年，SEC 以证券欺诈起诉 Garza。
- 2018 年，Garza 认罪电汇欺诈，被判 21 个月联邦监禁并追缴 910 万美元。
- 多数 Hashlet「投资人」损失了大部分本金。追偿顶多算部分。

为什么这值得一个词条而不是脚注：

- **云挖矿这个品类被骗局主导。** Hashlet 是比特币语境下[跑路盘](/glossary/rug-pull)的教科书案例——卖给你以不存在的东西背书的份额或代币、用新钱付旧账、新钱一断就消失。HashOcean、BitClub Network、Mining Capital Coin、USI-Tech 等，整个 2010 年代后期都在复刻这个模式。
- **模式从未变过。** 承诺你无法独立验证的算力收益；用新投资人的钱付老投资人；新钱减速即崩盘。
- **正经云挖矿存在**（NiceHash 算力市场、部分托管矿机服务），但那是个利基市场，不是骗局嘴里「躺赚挖矿」的样子。

对今天的自我托管比特币人，教训是结构性的：一个收益产品若拿不出真实产出算力的硬件、不让你验证链上分红能追溯到真实区块奖励、却支付「好得不像话」的回报，几乎必然是 Hashlet 式骗局。比特币挖矿敞口的诚实形态：自己买 ASIC 和电，或通过正常资本市场买矿业公司股票。两者之间的一切，历史成绩单都不佳。
