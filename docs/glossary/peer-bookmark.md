# 对等节点书签（Peer Bookmark）

> **一句话定义：** 节点的可选功能：保存特定节点的 IP 或洋葱地址，便于重连或加白。

「对端书签」是 Bitcoin Core 固定对端配置项的非正式叫法：

- `-addnode=<ip>`——在常规节点发现槽位之外，持续尝试连接某个特定对端。连接断了，节点会自己重试。
- `-connect=<ip>`——只连接指定对端，并彻底禁用 DNS 种子查询。用于完全受控的拓扑：私有网络、实验环境，或偏执的生产配置。

典型用途：

- 商户的支付处理节点与异地数据中心的备份节点保持直连，让区块和交易在两者间以最小延迟传播。
- 玩家的家庭节点连到朋友的节点，让区块在彼此间比随机发现更快直达。
- 「瞭望塔」或监控布置：一个节点是权威源，其余节点镜像它。

配合 `-whitelist` 设置可豁免这些对端的限流和封禁计分。多数公开节点完全不需要这些——默认的 DNS 种子加地址 gossip 运转良好，对几乎所有人都是正确选择。
