# 商家采用（Merchant Adoption）

> **一句话定义：** 商家逐步接受用比特币支付真实商品与服务的缓慢、不均匀的过程。

商家采用是指企业接受比特币作为真实商品与服务付款方式的缓慢且不均匀的过程。它是比特币货币化进程中不起眼的那一半——另一半是投资需求，占尽新闻头条。

2026 年真实的商家采用长什么样：

- **闪电优先。** [闪电网络](/glossary/lightning-network)解决了链上比特币解决不了的实际问题：支付几秒确认、手续费不足一分钱、即时结算让价格暴露降到最低。Strike、Phoenix、Cash App 等产品让接入闪电收款变得轻而易举。
- **萨尔瓦多的实验。** 自 2021 年起比特币在萨尔瓦多是法定货币。采用情况喜忧参半——游客中广泛使用，国内日常使用有限，基础设施（Chivo）出过不少毛病。但作为「当一个国家积极推动比特币支付会发生什么」的真实测试，它很有参考价值。
- **小商家长尾。** 全世界的咖啡馆、自由职业者、小企业，多数通过 Strike、Phoenix 或类似产品接入闪电。全球规模难以量化，但看得见的长尾一直在变长。
- **比特币工资服务。** Bitwage、Strike 的工资产品等，让员工把工资的一部分直接换算成 BTC。
- **对加密友好的银行卡。** 从 BTC 余额扣款、在商家端自动换成法币的借记卡。严格说不算「比特币支付」（商家收到的还是法币），但是可用的混合方案。

拖慢采用的因素：

- **波动性。** 商家在 BTC 价格 50 美元时收款、十分钟后以 48 美元换成法币，净亏 4%。闪电 + 即时结算有帮助，但底层资产仍然是波动的。
- **资本利得的会计麻烦。** 在大多数司法辖区，花掉 BTC 是应税事件。这种记账摩擦真实存在，让人不愿日常使用。
- **现有支付基础设施。** 银行卡、ACH 转账、银行转账根深蒂固、商家成本低、对多数人「够用了」。换用比特币的理由必须足够硬。

令人鼓舞的趋势：闪电收单现在在费率上已能与信用卡收单竞争，结算速度还更快。随着波动性问题（长期看）缓解、随着更多人直接以聪为单位获得收入，「用比特币付款」正从猎奇变成真实选项。规模化还没到，但方向是对的。
