# 燃烧地址（Burn Address）

> **一句话定义：** 一种私钥不可知的地址：打到那里的 BTC 等于退出流通，永远取不回来。

燃烧地址是私钥可证明无人知晓的比特币地址。发进去的币永远无法花费，因为凑不出能认领它们的签名。

构造燃烧地址的三个常见办法：

- **可证明无主的虚荣地址。** 像 `1BitcoinEater...` 这类图案，专门挑成「一看就是故意的、而且花不掉」的样子。完整地址终究要从哈希导出，意味着理论上存在某个私钥，但想碰巧找到它的概率是天文数字级的低。
- **`OP_RETURN` 输出。** 严格说这些根本不是地址，而是脚本被刻意写成「永远无法花费」的输出。Bitcoin Core 甚至不把它们当作 [UTXO](/glossary/utxo-unspent-transaction-output) 索引。常用于在链上嵌入数据（时间戳、承诺、证明）。
- **数学上不可能的地址。** 从「魔法」哈希输入（全零、某句口令的 SHA-256 之类）导出的地址，任何现实的密钥搜索都还原不出来。

为什么有人故意烧币：

- **Proof of Burn。** 一些侧链的启动机制要求参与者在主网烧掉 BTC 换侧链币。真金白银押上去，没有轻松撤销的口子。
- **象征性销毁。** 表明对某个协议的承诺、表达抗议、或者公开立个誓。
- **罚没资产处置。** 各国政府偶尔销毁查抄的币；打给燃烧地址是办法之一（更常见的是转入国库地址）。

还有一类悄无声息的「燃烧」：意外损失。丢掉的种子、坏掉的硬盘、无人能复原密钥的地址。各家估算口径不一，大约有 300–400 万枚 BTC 已经实际灭失。它们不是仪式性的燃烧，但对供给的净效果一模一样。

往燃烧地址打币，设计上就不可逆。没有恢复流程，也没有可以申诉的人类。真要做，务必想清楚再动手。
