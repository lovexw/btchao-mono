# 牛市（Bull Market）

> **一句话定义：** 价格持续上涨、情绪持续高涨的时期——比特币至今约四轮大周期，每轮顶部都在减半后 12–18 个月出现。

牛市是价格持续上涨、乐观情绪不断升温的时期。这个词来自传统金融，适用于任何资产；在比特币这里，它有自己的节奏。

截至 2025 年的价格史大约有四轮大牛市周期，每轮在[减半](/glossary/halving-halvening)后 12–18 个月见顶：

- **2010–2011**：0.001 美元 → 30 多美元。「早期采用者」时代。
- **2013**：13 美元 → 1,100 美元。Mt. Gox / 丝绸之路时代，以大型交易所事故收场。
- **2016–2017**：400 美元 → 20,000 美元。SegWit 激活、散户狂热。
- **2020–2021**：5,000 美元 → 69,000 美元。疫情印钞、MicroStrategy 和特斯拉入场、萨尔瓦多采用。
- **2024–2025**：40,000 美元 → 100,000 美元以上。现货 ETF、减半后周期延续。

这个规律是真的。至于它是不是因果（[减半](/glossary/halving-halvening)减少供给、需求追上、价格上升）还是巧合（周期因别的原因发生、只是碰巧和减半对齐），争论从未停过。n=3 或 n=4 个完整周期，数据量不足以严谨定论。

牛市里可靠的规律：

- **身在其中的时候，感觉它会永远涨。**「这次不一样」这句话你会听到很多。有时真不一样；通常不一样的是你亏钱的方式。
- **招来投机过热。** 山寨币、杠杆、复杂衍生品、NFT，一切有故事的都来。周期结束时，其中多数跑输 BTC。
- **它会结束。** 或以一个明确的见顶后转熊，或转入缓慢阴跌。转折点在实时中几乎从不明显。

比特币者的牛市纪律：记住波动是对称的——把资产推上去的力量，同样会把它砸下来。整个周期里坚持[定投（DCA）](/glossary/dca-dollar-cost-averaging)和 [HODL](/glossary/hodl) 的人，通常比试图择时的人做得更好。对「这轮顶在哪」的预测，娱乐性强、可靠性差。
