# 纸手（Paper Hands）

> **一句话定义：** 俚语：一有波动或恐慌就迅速卖币——「钻石手」的反面。

「纸手」是黑话，指市场下跌时把比特币卖掉而不是扛过去的行为。反面是「钻石手」——不管价格怎么走都拿着。

这个词出自梗文化，但背后的行为是真实的、被充分研究过的。多数交易者——散户和专业选手都算上——跑不赢简单的买入持有。原因会叠加：

- **在接近底部时恐慌卖出。** 熊市在当下感觉像世界末日。价格跌去 70% 之后，脑子里那个末日预言的声音很难不理会。在那一刻卖出的人，把亏损钉死了。
- **过早止盈。** 在多年牛市里卖出 10% 的利润，等于把后面大部分涨幅留在桌上。
- **再以更高的价格买回。** 卖出之后，你要么是对的（自我感觉良好），要么是错的（想要重新上车就得比卖出价更贵地买回）。多数人最终买得比自己卖的贵。

相反的纪律——[HODL](/glossary/hodl)，俗称钻石手——在比特币历史上每一个多年窗口里，经验上都是更优策略。不是因为拿着不动有多聪明，而是因为另一种做法要求你的择时能力超过几乎所有人，而你不是。

两句诚实的补丁：

- **确实有正当的卖出理由**，不算纸手：真正的紧急开支、按计划把币换成现实世界的消费、或者比特币占你净资产的比例已经高到不理性需要再平衡。健全的货币不等于永远不换东西。
- **「钻石手」的梗也可能是邪教话术。** 拿到归零和纸手抄底卖，结局一样糟。卖出一部分、锁定现实世界的成果，不是软弱。

纸手指的是一种**恐惧驱动的交易模式**。这个模式不好。出于生活原因的、有选择的、深思熟虑的卖出，不是纸手。
