# 比特币卫星（Bitcoin Satellite）

> **一句话定义：** Blockstream 通过地球同步卫星广播比特币区块——一个约 45 厘米的小锅加两三百美元的接收器，节点就能在没有互联网的地方实时追块。

比特币卫星是 Blockstream 通过地球同步卫星对比特币区块的广播。租用的数个转发器覆盖了地球上绝大多数人口区域。一副小型只收 dish（约 45 厘米）加一台 200–300 美元的接收器，就能让一个节点在完全没有互联网连接的情况下获得实时区块流。

实际用途比宣传语要窄。你仍然需要某种方式广播自己的交易：一部有手机信号的手机、一个短信网关、或 Blockstream 付费的卫星上行服务（把消息排队发上卫星）。所以对普通用户而言它还不算「无互联网的比特币」。但它确实意味着：

- 审查网络中的节点可以在不暴露自己在运行比特币的情况下保持链状态最新——天线指向的是卫星，不是某台服务器。
- 偏远地区、互联网时断时续的节点可以用卫星补上缺口。
- 整个网络多出一条冗余的、难以干扰的区块分发通道，不依赖任何单一 ISP、国家或对等互联安排。

这是一个「知道它存在就好」的基础设施。多数有可靠互联网的节点运营者永远用不上它。但对需要它的少数人来说，这就是节点能不能用和节点变砖的区别。
