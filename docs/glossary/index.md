用大白话解释比特币的每一个术语——从你转账用的「地址」，到决定协议如何演进的「BIP」。没有营销，没有黑话砌墙。

每条术语的结构都一样：**先一句话定义**，再展开——它机械上是什么、为了解决什么问题、代价是什么、和相邻概念是什么关系。
