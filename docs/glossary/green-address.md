# 绿色地址（Green Address）

> **一句话定义：** 一种历史概念：由知名机构担保「不会双花」，让收款方把未确认交易当作已确认来接受。

「绿色地址」是一个基本已成历史的想法：一笔交易因为出自某个有名有信用的实体——它保证不会双花——而被当作「等于已确认」来信任。收款方在交易到达的那一刻就把它当终态。

最初的方案（Mt. Gox 时代，约 2011–2013）有具体套路：

- 托管方公布一个指定的「绿色」地址。
- 托管方承诺永远不从该地址双花。
- 商户收到来自绿色地址的付款就立刻记账发货，信的是托管方的承诺，而不是等确认。

它没能成气候，理由很硬：

- **中心化信任。** 承诺的成色取决于托管方的偿付能力和诚实程度。商户这下要信两方：交易对手 + 托管方。这恰恰是比特币要干掉的东西。
- **「我信托管方」这条路**有更简单的实现：干脆整个用托管结算系统，跟信用卡一样。徒增密码学复杂度、不添半分安全，图什么。
- **更好的替代品出现了。** [闪电网络](/glossary/lightning-network)用密码学终局性解决了「快速结算」，不需要托管信任。

这个词偶尔还会在「可信比特币」服务的营销里冒出来，承诺对打到知名地址的付款即时入账。放到今天看，每一例卖的都是披着比特币术语的托管信任——对某些用户有用，但那不是比特币的本意。

2026 年的实用建议：要快速结算，用闪电网络。要知名机构给你即时入账，那机构直接给你入账就行，即时入账这一环根本不需要比特币在场。「绿色地址」是那些选项还不存在年代的一件博物馆藏品。
