# 区块浏览器（Block Explorer）

> **一句话定义：** 在线工具：搜索区块链数据——交易、地址、区块等。

区块浏览器是浏览比特币链的 Web 界面。输入一个[地址](/glossary/address)、[交易](/glossary/transaction) ID 或区块高度；拿回关联的链上数据：余额、交易历史、确认数、手续费、内存池状态。

区块浏览器人人有用，也人人是隐私妥协。你的每次搜索都告诉运营者你关心哪些地址或交易。随手查查无所谓；查自己的钱包就是隐私泄露——会被与你的 IP、浏览器指纹和现有 cookie 关联。

2026 年的主流浏览器：

- **mempool.space**——开源、有 Tor 镜像、可对着自己的节点自托管（费率市场可视化的标准参考）。
- **ChainQuery.com**——本站配套的比特币浏览器。界面干净，无跟踪，由独立节点供数。
- **blockchain.com、blockchair、blockstream.info**——更老或更商业化的替代品，隐私政策各异。

对隐私敏感的场景：跑自己的节点，用本地浏览器（自托管的 mempool.space、BTC RPC Explorer）。[全节点](/glossary/full-node)加本地浏览器意味着*只有你*看到链数据——没有第三方记录你的查询。

日常的「我的交易确认了吗」「当前费率行情如何」这类问题，公共浏览器完全没问题。只是别把你储蓄钱包的地址到处粘进搜索框。
