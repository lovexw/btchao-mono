# 激励相容（Incentive Compatibility）

> **一句话定义：** 一种机制的博弈论性质——理性的自利参与者发现，守规矩比坏规矩更赚钱。这就是比特币能在一个满是对手的去中心化世界里运转的原因。

激励相容是一种机制设计中的博弈论性质：理性、自利的参与者发现，遵守规则比破坏规则更有利可图。正是它让比特币在充满对手的去中心化世界里运转。

它体现在比特币的哪些地方：

- **矿工**烧电计算工作量证明。只有区块被网络接受，他们才能拿到区块补贴加手续费。产出无效区块（PoW 错误、无效交易、超出区块重量上限）会被拒收，电费白烧。产出有效区块则赚得奖励。经济上理性的矿工跟着规则走。
- **节点**对照共识规则验证每一笔交易。哪怕无效区块累积了更多工作量证明，节点照样拒绝。接受无效区块对节点毫无好处——没有奖励、没有手续费，只有一本错账，让自己在以为有效的交易上亏钱。
- **用户**为了让交易更快确认，自愿向矿工支付手续费。矿工优先打包费率最高的交易，因为那最赚钱。
- **51% 攻击**在数学上可能，在经济上自杀：有足够算力改写历史的矿工，会亲手摧毁自己挖的那种比特币的价值。攻击成本超过收益，所以攻击不会发生。

激励相容论证有边界。它假设参与者理性、会把短期收益对照长期价值打折。对于动机非货币化的行为者（国家级对手、意识形态狂热者、以捣乱为业的网络巨魔），或者能把成本外部化的行为者（偷来的电跑算力、托管机构的偷币），论证可能失灵。

但这个结构性属性对主流经济行为者在绝大多数时间成立，而这正是全部所需。比特币不要求人人诚实；它要求在总体上，诚实的行为者比不诚实的更赚钱。这场实验已经跑了快二十年，这个属性至今经受了实证检验。
