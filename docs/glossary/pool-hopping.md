# 跳池（Pool Hopping）

> **一句话定义：** 在矿池之间切换以钻其奖励系统空子的策略，现代矿池已基本堵死。

跳池是一种历史性漏洞利用：在矿池之间切换，钻结算方案的空子套取超常收益。它在 2010–2012 年是真实问题；现代矿池奖励系统已让它实际上不可能。

有漏洞的方案是**按回合比例结算（proportional payout）**：一回合结束（找到区块）时，矿池按本回合各矿工的份额比例分配奖励。数学问题在于：跳池者可以挖「早期份额」（此时每份额的期望回报高，因为区块还没被找到），在「晚期份额」（回合继续、期望回报大幅走低）拉低收益前撤退。

现代矿池怎么防：

- **PPLNS（按最近 N 份份额结算）。** 奖励按最近提交的 N 份份额分发，不看回合边界。跳进跳出没用，因为你的份额贡献永远按你最近的活动计，而不是按它落在哪个回合。
- **PPS / PPS+ / FPPS。** 矿池按固定期望值费率给每份份额付款（含矿池费），不管区块实际何时找到。方差由矿池吸收。每份份额价值相同，矿工无从择时套利。
- **积分制。** 各类按份额在回合中的位置加权的变体——早份额减值、晚份额增值，中和跳池优势。

2026 年，跳池在主流矿池中已基本不成问题。Foundry、AntPool、F2Pool、ViaBTC、MARA Pool 等都用能防跳池的现代奖励方案。这个词流传下来，主要是作为一个历史案例：分布式系统里微妙的激励错位，会被无情剥削，直到设计变好。

相邻的（仍然相关的）变体：出于正当运营理由的换池——比较费率、结算安排、到矿池服务器的地理延迟——那只是正常的矿池选择，不是 exploit，而且是挖矿市场健康的一部分。
