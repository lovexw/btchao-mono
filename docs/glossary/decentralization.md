# 去中心化（Decentralization）

> **一句话定义：** 把控制权与决策分散到众多参与者手中，而不是集中于一个中央权威。

去中心化是「不被任何人控制」这个属性本身。对比特币来说，正是它让其余一切都成为可能。没有它，协议的其他主张——抗审查、固定供应、中立、无许可——全部坍塌。

比特币在好几条不同的轴上去中心化：

- **验证。** 每个[全节点](/glossary/full-node)独立验证每个区块。全球运行着数以万计的全节点，没有任何一方能集体掌控它们。想改写历史，攻击者得说服其中多数独立验证者——也就是改变运行在数万名独立个人拥有并运营的硬件上的软件。
- **挖矿（算力）。** 分散在众多运营主体、司法辖区和所有权结构之间。中心化的担忧真实存在（见[挖矿中心化](/glossary/mining-centralization)），但没有任何单方掌控多数算力，而且新增边际算力是真无许可的。
- **开发。** Bitcoin Core 由一群轮换的独立贡献者维护，没有正式的层级结构。变更要经过公开评审。没有 CEO、没有公司、也没有哪个金主能指定路线图。
- **治理。** 比特币没有公司意义上的治理。协议变更靠自愿采纳发生：一个 [BIP](/glossary/bip-bitcoin-improvement-proposal) 被提出、被辩论、被（可选地）实现，只有足够多的独立节点运营者选择运行新代码时才实际生效。没有任何中央决策者能强推任何事。
- **地理分布。** 节点和矿工遍布各大洲以及政治与法律体系迥异的国家。没有任何单一监管者能让比特币下线。

去中心化不是非黑即白；它是一条光谱，也是一项持续被争论的属性。挖矿中心化是真问题。某些钱包软件、交易所基础设施和 BIP 作者群体的高度集中也是。这个协议比计算领域几乎所有其他东西都更去中心化，*同时*也确实存在值得警惕的中心化向量。

去中心化的反面不是「暴政」，只是「寻常」。金融系统里的几乎每样东西——银行、支付网络、央行、托管服务——都有一个可以被传唤、被威胁、被收买或被关停的责任方。比特币的去中心化是它与众不同的根本所在。守卫它，是每个人的事。
