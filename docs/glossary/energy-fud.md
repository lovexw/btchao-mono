# 能源 FUD（Energy FUD）

> **一句话定义：** 不提可再生能源占比、电网调节收益等细节、一味抨击比特币 PoW 能耗的批评。

「能源 FUD」是比特币社区对比特币[工作量证明](/glossary/proof-work-pow)能耗批评的称呼——社区认为那些批评有误导性、操纵性或技术上无知。像更广义的 [FUD](/glossary/fud-fear-uncertainty-doubt) 一样，这个标签有时用得其所，有时被用来草率打发正当担忧。

对「比特币浪费能源」框架保持怀疑的诚实理由：

- **比特币挖矿向弃置能源迁移。** 弃水电、火炬天然气、低谷核电、被削减的风电——这些电否则就是浪费掉的。边际挖矿业务用的正是没人在竞价的能源。
- **比特币不直接烧油烧气。** 它消耗的是电，而电越来越多来自可再生。「比特币碳足迹」的计算完全取决于电网结构假设，而各辖区天差地别。
- **挖矿可以稳定可再生电网。** ERCOT（得州）有把比特币矿工作为灵活负荷的正式项目：电网需求飙升时矿场几秒内关停，释放容量。这是常规工业负荷给不了的电网服务价值。
- **能耗就是安全。** 比特币的工作量证明让攻击链条变得昂贵。去掉能耗就是去掉安全。

但依然值得担忧的诚实理由：

- **部分挖矿烧的是煤等高排放源。** 不全是弃置可再生。真实电网结构要紧。
- **热与噪音的外部性。** 矿场产生让附近居民直接承受的局部污染。
- **总规模是真实的。** 比特币全球挖矿年耗电在数百亿 kWh 量级——即使边际业务用弃置电，总量也是真实数字。

「能源 FUD」这个标签，用在无视以上细节的说法上最贴切——「比特币耗电超过某国」却不给语境、「每笔比特币交易耗电 X kWh」这种混淆边际与平均能耗的计算。用在*任何*能耗担忧的条件反射上，最不贴切。

比特币玩家的纪律：不要一揽子打发能耗担忧，去回应批评的最强形式。最强形式有答案；弱形式之所以被叫 FUD，是因为它们没有。

哪些批评形式有答案、哪些没有，完整版见[比特币与能源](/rabbit-holes/energy)。
