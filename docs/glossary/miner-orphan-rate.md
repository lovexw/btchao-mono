# 矿工孤块率（Miner Orphan Rate）

> **一句话定义：** 矿工产出的区块未进入最长链的百分比，多因传播延迟或几乎同时出块。

孤块率是一个矿工产出的有效区块中，最终没进正统链的比例——这些区块输掉了几乎同时发生的竞赛，在网络收敛到另一个链尖时被抛弃。

严格说「orphan（孤块）」是误称。输掉竞赛的区块规范上叫*过期块*，「孤块」专指父区块尚不可知的块。但口语用法沿袭至今。

孤块为什么发生：

- 两个矿工几乎同时各自挖到有效区块，互相不知情。
- 两个区块都在网络上传播。
- 有的节点先看到 A，有的先看到 B，各自在看到的链尖上挖。
- 下一个区块被找到时，它建在两者之一上；另一个变成过期块。

对个体矿工，孤块率就是直接损失的收入。每块孤块等于烧了电、产出一个颗粒无收的区块。

什么驱动它：

- **区块传播延迟。** 你的区块到达其他矿工越慢，竞争区块抢先达到临界规模的机会越大。
- **地理位置。** 远离网络连接中心的矿工处于结构性劣势。
- **矿池归属。** 大矿池有更好的中继基础设施（与别的矿池直连、FIBRE 成员资格等），孤块率比用家庭宽带 solo 挖的矿工低。

2026 年的典型孤块率：连接良好的工业挖矿运营低于 0.5%；家庭网络上的爱好 solo 矿工 1–3%；地理边缘可能更高。

比特币的难度调整大体上吸收了孤块的全网效应：丢掉的区块不改变平均出块间隔，只是矿工之间的收入转移。但对任何个体矿工，孤块率是真实的、被认真记账的经营成本。
