> **本章目标：** 认真看清「去中心化」到底指什么、比特币落在光谱哪个位置，以及一个无人负责的网络凭什么能一次次击退接管企图。

![](/images/journey-network-topology.svg)
*一边是央行：单一枢纽。另一边是比特币：几万个对等节点，没有中心，没有开关。*

## 1. 三种网络形状

1960 年代初，兰德公司一位叫保罗·巴兰的工程师想设计一张能在核打击下幸存的通信网络。他画了三种形状：

- **中心化。** 一个枢纽。所有节点都连着枢纽。枢纽没了，网络没了。最高效，也最脆弱。
- **去中心化。** 若干枢纽，各带一群节点。丢一个枢纽黑一片，其余存活。还是枢纽制，只是多了几个。
- **分布式。** 没有枢纽。每个节点直接连接若干邻居。网络可以丢掉大半自己，幸存者照常通信。

我们随口叫「去中心化」的东西，多数其实是中间那种——联邦制。真正的分布式比这个词暗示的罕见。比特币主张的是第三种形状：强意义上的分布式。

## 2. 「去中心化」不指什么

这个词已经被用滥了。一些顶着「去中心化」之名的东西，其实不是：

- **「上链了，所以去中心化。」** 多数区块链的验证者屈指可数，有时 literally 就一小撮。把数据库搬到区块链上不会让数据库去中心化，只会让它变慢。
- **「多家公司共同运营。」** 联邦不是分布。Visa、Mastercard、SWIFT 都「联合」着一大堆成员机构，但只要其中几家串通，网络就被控制了。比特币给的不是这个。
- **「代码开源。」** 开源是去中心化的必要条件，不是充分条件。一大堆开源项目被一家公司或一个基金会管得死死的。
- **「由代币持有者治理。」** 按持币量加权的投票，是绕了个弯的财阀政治。几个巨鲸就能决定结果。

比特币意义上的去中心化*真正*指：**没有任何单一方——或可串通的小团体——能够强制更改规则、审查用户或关闭网络。** 检验标准不是看股权表上都有谁，而是看*谁能被胁迫*。

## 3. 比特币的位置

比特币是人类建过的最去中心化的货币系统。三类参与者，各司其职，互相制衡。

**节点运营者。** 任一时刻约有 17,000 到 22,000 个可达节点在线，算上防火墙后不可达的估计有 50,000 到 100,000+。任何运行比特币软件、验证每笔交易和区块的人。每个节点执行的规则定义了*在那条链的副本上*比特币是什么。你不赞成某个改动，就不运行新软件，你的节点继续按旧规则运作。节点跑在一台笔记本、一块树莓派、任何有硬盘的便宜电脑上。无需任何人批准。实时数量可在 [bitnodes.io](https://bitnodes.io) 查看。

**矿工。** 用专用硬件竞相出块换奖励，地理上分布在美国、俄罗斯、哈萨克斯坦、加拿大、西欧等地。他们产出区块，但*不制定规则*。矿工产出违反共识的区块，所有节点拒绝，电费白烧。**矿工跟随节点，而不是相反。**

**开发者。** 写软件的人。[Bitcoin Core](/glossary/bitcoin-core) 是主流实现，但 Bitcoin Knots、btcd、Libbitcoin 是同一协议的独立实现。开发者可以提议变更，不能强加。给 Bitcoin Core 提的变更，要说服几千个节点运营者真的去运行新代码才行。十六年来 Core 有一千多位贡献者，没有任何单人的提交量超过几个百分点。

**集中度隐忧，以及结构性对冲。**

矿池集中：头几个矿池控制全球多数算力。听着吓人，直到你意识到**矿池并不拥有算力**。个体矿工（每个矿池常有数千个）把机器指向给条件最好的矿池。哪个矿池想攻击网络，矿工几天内就走光了。2014 年 GHash.io 逼近 51% 时正是如此，几周内矿工自发迁出。

实现集中：Bitcoin Core 按节点数占绝对多数。如果 Core 开发者被捕获，这是真实风险。对冲手段是替代实现的存在（必要时可以快速推上前）以及 Core 的评审流程——几十位独立贡献者都有权拒绝合并。

这些不是完美保护。它们只是优于人类试过的所有其他货币系统。

## 4. 2017 年的接管企图

比特币去中心化最清晰的一次压力测试发生在 2017 年。

一批大矿池、交易所和比特币公司签署了**纽约协议**（NYA）。计划：激活 [SegWit](/glossary/segwit-segregated-witness-bip-141) *外加*硬分叉把区块大小翻倍，打包成 SegWit2x，简称「2x」。签署方代表了约 80% 的算力和业内绝大多数重要企业。

看上去压倒性的共识。其实不是。

一场叫 **UASF**（用户激活软分叉，围绕 [BIP 148](https://github.com/bitcoin/bips/blob/master/bip-0148.mediawiki) 组织）的草根运动并行展开。数千名节点运营者承诺：无论矿工是否支持，都在 2017 年 8 月 1 日强制执行 SegWit，并拒绝不给 SegWit 信号的那些矿工的区块。UASF 支持者戴黄帽子、换推特头像。营销很滑稽，协调出的网络立场一点也不。

实际发生的事：

- SegWit 于 2017 年 8 月 23 日顺利激活。面对 UASF 威胁的链分裂，矿工多数派让步了。
- 2x 硬分叉定于 2017 年 11 月，在预定激活前 **3 天被取消**。一旦节点运营者明确不运行新软件，协议就散了。签署方有算力、有钱，但他们的节点跑的仍是旧规则——他们根本强迫不了这次变更。
- 更早的 2017 年 8 月 1 日，另一拨人分叉出去创建了大区块的 Bitcoin Cash。如今是一条独立网络，市值只有比特币的零头。

**教训藏在机制里。** 矿工有算力，企业有钱，开发者有关注度，但这些群体都不是决策者。决策者是那几千个选择运行什么软件的节点运营者。在笔记本上跑节点的普通人，正是共同决定「比特币是什么」的人。

这就是「没有人说了算」的实际样子。不是没有规则——规则严苛到极致——而是没有一个能改规则的中心方。

## 5. 怎么衡量它

去中心化难以量化。几个不完美的指标放在一起，能拼出画像：

| 指标 | 比特币 | 说明 |
| --- | --- | --- |
| 可达节点 | 17,000–22,000 | 执行规则者的下限 |
| 估计总节点 | 50,000–100,000+ | 含不可达节点的真实规模 |
| 第一大矿池算力占比 | 浮动，约 25–35% | 最大单一出块协调者 |
| 前五大矿池算力占比 | 浮动，约 80–90% | 集中度风险（被矿工流动性缓解） |
| 矿业地理分布 | 8+ 国有显著份额 | 辖区分散度 |
| 独立客户端实现 | 4+（Core、Knots、btcd、Libbitcoin） | 代码层多样性 |
| Bitcoin Core 贡献者 | 16 年 1,000+ | 开发无单点 |

对比之下，多数自称「去中心化」的链有 10–200 个验证者、单一客户端、外加一个实际控制路线图的基金会或团队。

这些指标不是终审判决。拼起来是一幅画：比特币是有史以来最分布式的货币系统，领先一个身位，同时在特定层面存在社区正在积极管理的真实集中度风险。

## 6. 去中心化表演

很多项目一边自称「去中心化」，一边跑在数据库与寡头之间的什么东西上。这个批评是公允的，而且应当一视同仁地——包括对 bitcoin——拿来检验。

去中心化表演的常见套路：

- **「无需许可。」** 谁都能加入，但升级全由一个小团体写。
- **「代币持有者治理。」** 治理投票实际由一小撮大户控制。
- **「验证者集合开放。」** 开放的前提是*质押几百万美元*、在指定数据中心跑指定硬件。
- **「代码在 GitHub 上。」** 是的，但 PR 只由一家基金会的雇员评审合并。
- **「我们是比特币的二层。」** 有时是真的，有时是一个自称「比特币周边」的联邦。

这些都可以是有用系统的特性。但它们不是比特币设计瞄准的东西，也过不了「谁能被胁迫」的检验。

比特币的主张是可检验的：任何人在任何设备上都能自己验证链条、运行自己的软件、拒绝自己不同意的变更。门槛是「无需许可，无需协调，只有数学和你选择运行的软件」。

这就是标准。健全货币就配这个标准。低于它的东西不是替代品，只是另一种产品。

## 7. 为什么难以替代

去中心化很贵。它消耗吞吐量、消耗能源、消耗开发便利性、消耗用户体验。多数区块链为了速度和功能在它身上妥协。

对很多用例，这是正当的取舍。对*健全货币*，这是致命的取舍——因为健全货币的全部职责，就是做一种没人能贬值、冻结、没收或单方面升级的价值储藏。一旦任何单一方能改规则，这钱就不再健全。

如果你接受「货币恰恰是最值得被保护免于被捕获的东西」这个前提，你就接受了为保护它而付出的去中心化代价。比特币就是这个选择的实现。

代价是真的。代价就是产品本身。

> **划重点：** 有人说某项目「去中心化」时，问一句：「如果这十个人串通，能不能改规则、冻结资金、关掉网络？」对多数自称区块链的东西，诚实的答案是能。对比特币，经过十六年的压力测试，答案仍然不能。这就是产品的全部。
