## 原则：账本是公开的

比特币是*假名*系统，不是匿名系统。每一笔链上交易、每一个地址的完整历史，对任何人永久公开。把身份和地址挂钩一次，过去和未来的关联就全部可见。

你的隐私没有产品可以代劳——它是一组习惯。好消息是：少数几个习惯能挡住绝大多数泄露。

## 十条隐私基本功

1. **永不复用地址。** 每次收款生成新地址。现代钱包默认这样做，别去改它。地址复用是把「这些收据都归我」写在公开账本上。
2. **使用硬币控制（coin control）。** 花费时手动挑选 UTXO，别让钱包自动合并。一笔交易里出现的多个输入会被视为同一个人的钱。
3. **KYC 币和未 KYC 币分开存放。** 交易所实名买来的币和点对点得到的币放在不同钱包，别让一笔交易把它们连起来。
4. **钱包流量走 Tor 或自己的节点。** 公共 Electrum 服务器看得到你查询的每个地址；自己的节点什么都看不到。
5. **网络层面防 IP 泄露。** 你广播交易时的 IP 不进区块链，但会被听得见的节点看到。Tor 或 VPN 能切断这条路。
6. **收发大额时分批、别合并展示。** 大额搬家尽量拆分进行，避免一笔交易暴露全部规模。
7. **公开场合不谈持仓。** 不发地址、不晒余额、不说设备型号。社交工程是真实威胁，匿名是自卫。
8. **小心找零暴露。** 找零地址如果和多签或新地址混用不慎，会把金额结构泄露给链上分析。钱包默认行为通常安全，自定义时要想清楚。
9. **警惕「验证工具」。** 任何要求你粘贴助记词、私钥、xpub 来「检查余额」的网站都是在偷你的钱。查余额用 [mempool.space](https://mempool.space) 输入*地址*即可，永远不需要密钥。
10. **认真对待 CoinJoin 类工具。** 混币能改善隐私也有合规与对手风险，用之前读[比特币隐私：什么有效、什么无效](/rabbit-holes/bitcoin-privacy)。

## 常见无效手段

- **换新钱包≠新身份。** 如果你把旧钱包的 UTXO 一笔转进新钱包，那笔交易就是公开的关联声明。
- **混币一次就归零暴露。** 混完的币若和未混的币合并存储，效果打回原形。
- **删除交易历史没有意义。** 链上历史不可删除，隐私策略永远是「从今天起不再新增关联」。

## 本站的隐私声明

一句话：**本站几乎不收集任何东西。**

- 这是纯静态站点（VitePress 构建产物托管在 Cloudflare Pages），没有数据库，没有账户系统。
- 不投放广告、不运行追踪器、没有营销漏斗、没有订阅邮件。
- 不设置任何自有的 Cookie 或 localStorage，你的浏览器里不会留下本站写入的数据。
- Cloudflare 作为 CDN 会按其自身政策记录 IP 以抵御滥用；本站不读取、不导出这些日志。

因此本站没有 Cookie 横幅——没有什么需要你同意的。
